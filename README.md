# MUNDO MOTOR — Dieth Alvarez

Proyecto académico de grado décimo sobre automovilismo.

## Ver la página
Abre GitHub Pages (cuando se active) en:
https://dieth0883-boop.github.io/dieth/

## Archivos
- index.html: página principal.
- css/styles.css: estilos de la página.
- js/main.js: funciones pequeñas de navegación.
- assets/: ilustraciones e ícono.
- ejercicio-modelo-caja/: ejercicio independiente de la semana 5.
- documentacion/: requisitos, mapa mental, guía de publicación y guía del estudiante.

## Publicación
En GitHub abre Settings → Pages. Selecciona Deploy from a branch, rama main y carpeta / (root), y guarda.
