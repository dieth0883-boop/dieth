# Mapa mental: servidores, hosting y dominios

## Tema central: publicar una página web

### 1. Servidor
- **Definición:** computador o sistema que ofrece servicios y responde a solicitudes de otros equipos.
- **Función:** entregar archivos y datos cuando una persona abre una página web.
- **Características:** está conectado a una red, utiliza programas de servidor y atiende solicitudes.
- **Tipos:** servidor web, servidor de archivos, servidor de correo y servidor de bases de datos.
- **Ejemplo:** un servidor web envía el HTML, CSS, imágenes y otros recursos del sitio al navegador.

### 2. Hosting o alojamiento web
- **Definición:** servicio que permite guardar los archivos de una página en un servidor conectado a internet.
- **Función:** mantener disponibles los archivos para que otras personas puedan visitar el sitio.
- **Características:** espacio de almacenamiento, transferencia de datos, disponibilidad y herramientas de administración.
- **Tipos:** hosting compartido, VPS, servidor dedicado y alojamiento en la nube.
- **Ejemplo:** GitHub Pages aloja sitios web estáticos desde un repositorio.

### 3. Dominio
- **Definición:** nombre fácil de recordar que identifica una dirección en internet.
- **Función:** permite llegar a una página sin tener que recordar una dirección IP.
- **Partes:** nombre y extensión, como .com, .org o .edu.
- **DNS:** sistema que relaciona el nombre del dominio con la dirección del servidor.
- **Ejemplo:** ejemplo.com.

### 4. Relación entre los tres conceptos
1. La persona escribe el dominio en el navegador.
2. El DNS ayuda a localizar el servidor relacionado con ese dominio.
3. El servidor o servicio de hosting guarda y entrega los archivos del sitio.
4. El navegador recibe esos archivos y muestra la página.

## Cómo convertirlo en un mapa mental visual
- En el centro coloca “Publicar una página web”.
- Crea tres ramas principales: Servidor, Hosting y Dominio.
- Desde cada rama agrega subramas: definición, función, características, tipos y ejemplo.
- Añade una cuarta rama llamada “Cómo se relacionan” y utiliza flechas para mostrar el recorrido desde el dominio hasta la página.
- Pasa este esquema a MindMeister, Lucidchart, Bubbl.us, Popplet o Creately y exporta el resultado como imagen o PDF.
