# Guía del estudiante — MUNDO MOTOR

## Archivos principales
- **index.html:** contiene el contenido y la estructura de la página.
- **css/styles.css:** define colores, tamaños, espacios y distribución.
- **js/main.js:** agrega funciones pequeñas para mejorar la navegación.
- **assets/images/:** contiene las ilustraciones SVG.
- **assets/icons/:** contiene el ícono del sitio.
- **ejercicio-modelo-caja/:** contiene el segundo ejercicio de la semana 5.
- **documentacion/:** contiene los requisitos y las guías.

## Explicaciones básicas
1. **¿Qué es HTML?** Es el lenguaje que organiza el contenido de una página.
2. **¿Qué es CSS?** Es el lenguaje que define la apariencia: colores, tamaños, espacios y distribución.
3. **¿Para qué sirve Bootstrap?** Es un framework que ofrece componentes y un sistema de columnas para organizar el diseño.
4. **¿Qué diferencia hay entre class e id?** Una clase puede repetirse en varios elementos; un id identifica un elemento específico.
5. **¿Para qué sirven section, article y aside?** Section agrupa una parte del contenido, article representa contenido que puede entenderse por sí solo y aside guarda información complementaria.
6. **¿Qué es el modelo de caja?** Es la manera en que CSS calcula el espacio de un elemento: contenido, padding, borde y margen.
7. **¿Qué hace hover?** Aplica un estilo cuando el cursor pasa sobre un elemento.
8. **¿Qué es hosting?** Es un servicio que guarda los archivos del sitio y los mantiene disponibles en internet.
9. **¿Qué es un dominio?** Es un nombre fácil de recordar que permite localizar un sitio web.
10. **¿Qué es GitHub Pages?** Es un servicio para publicar sitios web estáticos desde un repositorio de GitHub.

## Cómo hacer cambios
- Para cambiar un texto, abre index.html y modifica el párrafo correspondiente.
- Para cambiar un color, abre css/styles.css y busca la regla del elemento.
- Para cambiar una imagen, reemplaza el archivo dentro de assets/images/ manteniendo el mismo nombre, o actualiza su ruta en el HTML.
- Para agregar una sección, crea un elemento section con un id único y agrega un enlace en el menú.

## Nota para la presentación
Lee el código y practica explicar los conceptos con tus propias palabras. La página usa Bootstrap 5 desde un CDN, por eso necesita conexión a internet para cargar el framework.
