# Guía para publicar MUNDO MOTOR en GitHub Pages

## 1. Preparar los archivos
- Asegúrate de que index.html esté en la raíz del repositorio.
- Mantén las carpetas css, js, assets, ejercicio-modelo-caja y documentacion.
- No subas contraseñas ni datos personales que no quieras hacer públicos.

## 2. Subir los archivos
1. Abre el repositorio: https://github.com/dieth0883-boop/dieth
2. Selecciona Add file y después Upload files.
3. Arrastra las carpetas y archivos del proyecto. No es necesario subir un ZIP comprimido.
4. Escribe un mensaje de confirmación, por ejemplo: “Subir proyecto MUNDO MOTOR”.
5. Pulsa Commit changes.

## 3. Activar GitHub Pages
1. En el repositorio abre Settings.
2. En el menú lateral selecciona Pages.
3. En Build and deployment, elige Deploy from a branch.
4. Selecciona la rama main y la carpeta / (root).
5. Pulsa Save.

## 4. Dirección esperada
La dirección tendrá este formato:
https://dieth0883-boop.github.io/dieth/

Espera a que GitHub termine la publicación y abre el enlace. No compartas la dirección como publicada hasta comprobar que carga correctamente.

## 5. Revisar el sitio
- Prueba todos los enlaces del menú.
- Comprueba que las imágenes aparezcan.
- Abre la página en un celular.
- Revisa el ejercicio de modelo de caja en ejercicio-modelo-caja/index.html.

## 6. Importante
El repositorio es público, por lo que cualquier persona puede consultar sus archivos. No publiques datos privados.
